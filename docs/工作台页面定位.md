# 工作台页面定位（2026-11-24 定稿：常浩回「就这样」）

这份文档定工作台每一页**回答什么、什么时候看、看完做什么、留哪几块、和飞书怎么分工**。以后改设计稿、做原型、接数据、写规格，先查这里。数据从哪来仍以 [工作台数据约定](工作台数据约定.md) 为准；样子以 [DECIDED](DECIDED.md) 登记的定稿为准，本文要改定稿的地方列在文末「要单独确认的改动」，没确认前不动设计稿。

来由：11-24 常浩说「每个页面到底是什么定位……到处都是密密麻麻的，底层反应是形式大于内容」，接实况第 1 批暂停，在会话「数字分身工作台｜重梳每页定位」里盘问六轮、做了一次 impeccable 双评审（21/40，报告存在 worktree 的 `.impeccable/critique/`）后定下。逐条原话记在共享笔记 `工作台定位盘问-记录.md`。术语见 [GLOSSARY.md](../GLOSSARY.md)，两条难回头的决定见 [ADR-0001](adr/0001-工作台和飞书分工.md)、[ADR-0002](adr/0002-工作台七页和信息主场.md)。

## 一、总的定位（六轮盘问定的）

1. **工作台管的是「数字分身」这套机制经手的事**，不按项目划：分身派的单、跑的定时任务、替你合并和代批的，加上你自己开的、分身在盯的 Claude 会话；亚古兽的工作内容只记跑没跑成、产出在哪，不显示内容。（第 2、3 轮）
2. **飞书叫你、也是你按批准的唯一地方；工作台不催**，只回答飞书一句话说不清的东西：全貌、来龙去脉、规则。（第 1 轮）
3. **每天固定看一次**（上午看完日报，十分钟内），加上飞书里某件事想追来龙去脉时点进来。（第 1 轮）
4. **第一版只看不改**：能点的只有跳转（去飞书卡、PR、会话、文件）和「关秘书」刹车。（第 1 轮）
5. **页面质感不能动，只换内容**：刊头、等距插画、点阵字、斜线阴影大按钮、黑底横条、细线、点阵底、等宽字体、橙色只给「我」和要注意的东西。质感元素不受下面「每块对应一个判断或动作」的限制。（第 4 轮常浩纠正）

## 二、页面定位表

侧栏：**今天、在办**（不带组名）｜**留痕**：记录、沉淀｜**规则**：协同、执行、分身。原八页里首页和汇报合成「今天」，主线改成「在办」。

| 页面 | 回答哪个问题 | 什么时候看 | 看完做什么 | 留哪几块 | 和飞书的分工 |
|---|---|---|---|---|---|
| **今天** | 从上次看到现在变了什么，有没有事要我处理（F11.2 五问各一句答案） | 每天上午看完日报一次 | 去飞书处理等你定的；点进在办、记录、规则页追某件事 | 刊头（换装五问答案）、经过、今天的运行 | 飞书推单子、点批准；今天页只出数字和「去飞书」，补来龙去脉 |
| **在办** | 进了系统还没完的事都在哪，哪件要我出手 | 从今天页的「等你定」「在推进」「出了问题」点进来；想查某件事时 | 去飞书处理「等你」的；去会话或 PR 推一把卡住的 | 状态数字条、主线进度行、按状态分组的事项表 | 午晚单只列要你亲手做的（最多 7 件），日报只列等你拍板的（最多 5 件）；在办列全部、带出处 |
| **记录** | 分身和工人做了什么、凭什么、结果怎样 | 今天页某条异常或「今天的运行」点进来；出了事翻旧账 | 判断某次动作对不对，要不要追查或推翻 | 翻日子、数字条、泳道时间轴、流水表、来源行 | 飞书不推流水，只在这里查 |
| **沉淀** | 分身发现了什么值得改，哪些已经变成规矩 | 今天页第 5 条有数时；周一提案推送后 | 去飞书定提案；催定了没落地的；盯再犯 | 四列看板、规矩库一行 | 每周提案卡在飞书定；这里看全貌和落地进度 |
| **协同**（规则） | 工作流按什么顺序接力，有哪些自动化 | 某单卡在某一步、某个自动化没跑成，点进来看规则 | 判断规则要不要改，要改去会话或飞书私聊说 | 五条通则、工作流（灰框）、自动化分组表 | 飞书不推规则 |
| **执行**（规则） | 活交给谁干，他们现在能不能干 | 某家执行方灯不对时；偶尔复查 | 判断要不要补登录、切默认，去终端或飞书办 | 五列工位、dt-worker、出问题怎么办、对外开放 | 飞书不推；切默认执行方只能在飞书确认 |
| **分身**（规则） | 分身能替我做到哪一步 | 秘书状态不对；想知道某条「替你定了」凭什么 | 判断要不要关秘书（这页能关）；改规则去私聊 | 8 道闸路径、「现在」、授权四档、私聊口令 | 开秘书、签清单、托管、解除冻结只认飞书私聊 |

## 三、全站规则

### 1. 每类信息只有一个主场

同一个数在别处出现时，只放「数字 + ↗」，点了去主场，数从同一个口径算（评审 P0：现在拍板 6 / 3 / 4、今天跑了 9 / 66、自动化 8+1 / 21 互相打架）。

| 信息 | 主场 | 别处怎么出现 |
|---|---|---|
| 等你定的事 | 飞书（批准）；工作台里在「在办」的「等你」组 | 今天：黑底标签、要点第 1 条、系统图「我」标注、大按钮，都是同一个数 |
| 还没完的事（卡住、等外部、在做、待验证） | 在办 | 今天：要点第 2、3 条 |
| 分身和工人做过的每一次动作 | 记录 | 今天：右栏「今天的运行」四个数和小时间轴 |
| 交代的事做完了（有证据） | 今天的「经过」 | 记录里能查到每一步 |
| 执行方能不能用 | 执行 | 侧栏底部灯、今天刊头的执行方小规格表；出问题时进今天要点第 3 条 |
| 秘书什么状态 | 分身 | 侧栏底部状态行；出问题时进今天要点第 3 条 |
| 工作流、自动化 | 协同 | 自动化没跑成时进今天要点第 3 条 |
| 提案、坑、再犯 | 沉淀 | 今天要点第 5 条 |

### 2. 时间口径

- 「今天」一律从 04:00 算到次日 04:00（和日报、记录页一致）。
- 「经过」从**你上一次打开工作台**算起（工作台在本机记一下看过的时间）；超过 3 天没看，只摊开最近 3 天，更早的折叠。（第 6 轮 Q15）
- 两处都在标题旁写清时间范围。

### 3. 只看

- 去掉：各页顶栏「+ 新建工作流」、首页底部新建框、托管·秘书四段开关、执行页「发起切到…」、各处「发起合并 / 退回 / 采纳」、协同页拖拽编辑和「改了，还没生效」一整段、分身页第 1 步开关和第 3 步按钮。
- 留下：跳转（去飞书 ↗、PR ↗、会话 ↗、文件 ↗）；「关秘书」：侧栏底部状态行常驻（秘书开着才亮，关着灰），分身页「现在」一块也有。（第 6 轮 Q16）

### 4. 没有数据来源的块：画灰框（第 5 轮 Q13 甲）

- 位置留着，画 1px 虚线框、透明底、不用橙色，不放示例数据。
- 框里一行字：「还没有数据来源 · 缺：〈缺什么〉」。
- 高度按一到两行，不按满数据的高度留大空框；相邻几块合成一个框逐条列。
- 接实况前各页哪些块是灰框，以数据约定为准、逐行重核（第二版前五页的行有过时的）。

### 5. 字号和颜色（impeccable 评审后常浩选的）

- 字号底线：正文最小 12px；中文正文 13px、行高 1.6；等宽字只给编号、时间、数字。插画里的小标注算装饰，不承载要读的信息，不受限。
- 橙色只给「我」和异常。状态标签收成一套：卡住、等你、等外部、在做、待验证，另加已完成，样式固定。
- 侧栏底部的字体说明删掉；「示例数据，不是实况」挪到页头。

## 四、每页留哪几块

每块写它对应的判断或动作；质感元素标「质感」。

### 今天（首页 + 汇报）

刊头（元素全留，高度从约 900px 压到约 660px，让「经过」标题露在首屏底部）：

| 块 | 装什么 | 对应 |
|---|---|---|
| 黑底标签 | 「N 件在飞书等你定 ✦」 | 动作：去飞书 |
| 大标题、日期 | 「数字分身 工作台」、现在几点、「上次看是 昨天 10:20」 | 质感；判断「经过」从哪算 |
| 一句说明 | 不变 | 质感 |
| ↗ 要点五条 | 五问答案各一行，点了跳出处：①等你定 N 件（最久 X 天）②在推进 N 件（分身派的 a、你开的分身在盯 b）③出了问题 N 处（卡住、没跑成的定时任务、不能用的执行方、秘书冻结）④做完了 N 件（有证据）⑤分身的发现 N 条 | 判断：今天要不要出手 |
| 执行方小规格表 | 不变（五家和灯） | 判断：哪家不能用 |
| 等距系统图 | 「我」标注「N 件 · 等你定」，其余不变 | 质感 |
| WORKBENCH 点阵字 | 不变 | 质感 |
| 斜线阴影大按钮 | 「去飞书处理 N 件 ↗」 | 动作：去飞书 |
| 右下 ↓ | 跳到「经过」 | 跳转 |

刊头下面：

| 块 | 装什么 | 对应 |
|---|---|---|
| 主栏「从上次看到现在的经过」 | 一件事一段，沿用汇报页甲版：标题行（序号、白话标题、状态、执行方和单号、用时）+ 这件事 / 经过 / 现在的结果，右栏「要你做」（要动的写「在飞书 ↗」，不放按钮）；三种标记（替你定的、没定的、做完的动作）。第一版**脚本拼事实句、不调 AI**（第 6 轮 Q14）；没有变化写一句「从上次看到现在没有变化」 | 判断：哪件事要追；动作：去飞书、去在办 |
| 右窄栏「今天的运行」 | 四个大数字 + 小时间轴（04:00 起），和记录页同一口径 | 判断：今天跑得正不正常；点了去记录 |

删掉：首页「等我拍板」清单行、工作流立方体段、托管·秘书小卡、自动化小卡；汇报页拍板卡片、报告页签、额度条。汇报页的六个数字和一夜时间轴没问过，见第六节。

### 在办（原主线）

| 块 | 装什么 | 对应 |
|---|---|---|
| 标题行 + 状态数字条 | 在办 N 件；卡住、等你、等外部、在做、待验证五格，点一格就筛到那一组 | 判断：先看哪一组 |
| 主线进度行 | 每条主线一行：名字、进度格 X/Y、卡在哪一站、上次巡视一句；默认收起，点开是 11-19 定稿的地铁线和任务单 | 判断：大目标走到哪 |
| 按状态分组的事项表 | 卡住 → 等你 → 等外部 → 在做 → 待验证。每行：哪件事、项目、是谁开的（分身派的 / 你开的、分身在盯）、谁负责、停了多久、下一步、出处 ↗；「等你」行尾「去飞书 ↗」或「你亲手」 | 动作：去飞书、去会话或 PR 推一把 |
| 项目筛选 | 按项目看 | 判断：某个项目卡在哪 |

删掉：原主线页的「等你」黑底横条（并进「等你」组）。

### 记录

| 块 | 装什么 | 对应 |
|---|---|---|
| 翻日子 | 04:00 起算，前后翻 | 动作：翻旧账 |
| 数字条 | 一共、失败、转给你、授权不够、结果不明，最后一格来源取到几个；每格点了筛选，含「只看要留意」 | 判断：这天有没有问题 |
| 泳道时间轴 | 六道（合并、派单、定时任务、判断、看管、安装），一天跑很多次的合成带「×N」的条 | 判断：问题出在哪个时段、哪一类 |
| 按钟点流水表 | 每次动作一行：结果、做了什么、对象、谁、几档、凭什么；要留意的行展开画出每一步 | 判断：这次动作对不对 |
| 来源行 | 八个来源各取到几条，没取到标红、不当 0 | 判断：数全不全 |

改：「要留意」那一栏改成时间轴和数字条上的筛选，不另列一栏（第 4 轮 Q11）。

### 沉淀

| 块 | 装什么 | 对应 |
|---|---|---|
| 四列看板 | 发现了等你定 → 你定了还没落地 → 本周写进规矩 → 本周再犯；卡片按钮改「去飞书 ↗」 | 动作：去定、催落地、确认、盯再犯 |
| 规矩库一行 | 「本项目坑 N · 全局坑 N · 已定内容 N」，点了打开文件 | 跳转 |

灰框：你定了还没落地（没有落地记录）、优化线索（没有来源）。

### 协同（规则组）

| 块 | 装什么 | 对应 |
|---|---|---|
| 五条通则 | 不变 | 判断：这单该不该停 |
| 工作流 | 页签、三格（什么时候开始、怎样算做完、上限）、泳道、泳道下的四行规则表（全部摊开，收紧对齐）。**工作流注册表没有，整段先是灰框**：「还没有数据来源 · 缺：工作流注册表」；设计稿留着当样子 | 判断：卡在第几步、按规矩下一步是谁 |
| 自动化 | 按负责人分组（猛鬼兽、亚古兽、Codex、Claude Code、本机），每个一行：名字和一句做什么、什么时候跑、在跑 / 已暂停 | 判断：某个自动化该不该跑 |

删掉：模块条、拖拽、列头「‹ › ×」、最右斜线格、「改了，还没生效」整段、「+ 新建」页签。

### 执行（规则组）

| 块 | 装什么 | 对应 |
|---|---|---|
| 标题行 | 几家、几家未登录、没点名派给谁、检查于几点 | 判断：有没有家不能用 |
| 左「你的账号」五列 | 每列顶上：名字、默认、模型、灯和原因、接入方式、额度（查不到写查不到）；挂的活收成「接了 N 件 ▸」，点开才列，五列等高 | 判断：活压在谁身上 |
| 右「dt-worker」 | 隔离、通不通、登没登录、派单规则暂停没有、做完还要人做哪步 | 判断：新底座能不能接活 |
| 默认执行方一行 | 「没点名的派单交给 X」，只显示 | 判断 |
| 另有 N 个脚本不用 AI | 不变 | — |
| 出了问题怎么办、对外开放 | 不变 | 判断：出事会怎样 |

删掉：「发起切到 … ↗ 飞书」按钮和撤回。灰框：额度查不到的、dt-worker 登录和联网检查（没有检查命令）、亚古兽单列（`ai_access.json` 还没拆）。

### 分身（规则组）

| 块 | 装什么 | 对应 |
|---|---|---|
| 标题行 | 秘书状态、清单版本和签没签、今天代批几次 | 判断 |
| 8 道闸路径 | 不变；第 1 道四段开关改成状态文字，第 3 道按钮改成只读标签；卡在哪一道照旧橙色 | 判断：秘书为什么交给我 / 凭什么替我定 |
| 右栏「现在」 | 秘书状态、每张卡停在第几道、「关秘书」 | 动作：关秘书 |
| 授权四档、在猛鬼兽私聊说 | 不变 | 判断；动作：去私聊 |

### 外壳

- 侧栏三组见第二节开头。角标只放「要你看的数」（评审 P2 的改法，具体样子原型时定）：今天 = 飞书等你定 N，在办 = 卡住 N，沉淀 = 等你定的提案 N；规则组三页只在出问题时亮一个点。
- 底部状态行：底座三盏灯、五个执行方灯、「关秘书」。
- 顶栏：去掉「+ 新建工作流」；日期和刊头不重复。

## 五、要单独确认的改动（全局规则第 15 节）

下面每一项都改已定内容。动设计稿之前逐项单独发「改动确认」，等常浩回复；这份定位表回「就这样」不算对这些项的确认。

1. 首页第 3 版、第 4 版：首页并进「今天」，拍板清单行、工作流段、托管·秘书和自动化小卡拿走，刊头换装内容、压高到约 660px。
2. 汇报页（11-19 重做）：并进「今天」，拍板卡片、报告页签、额度条拿走，「经过」留下（六个数字、一夜时间轴待定）。
3. 侧栏四组八入口（第 4 版第 1 条）：改成三组七页。
4. 主线页（11-19）：改名「在办」、按状态排、主线压成进度行默认收起、「等你」横条并进「等你」组。
5. 协同页（11-19）：拖拽编辑、模块条、「改了，还没生效」去掉；工作流段先成灰框。
6. 执行页（11-24）：「发起切到…」按钮去掉、挂的活收起。
7. 分身页（11-19）：第 1 道开关、第 3 道按钮改成只读；「关秘书」多一个侧栏入口。
8. 记录页（11-24）：「要留意」栏改成筛选。
9. 沉淀页（11-24）：规矩库三栏缩成一行，按钮改「去飞书 ↗」。
10. 首页第 3 版第 2 条视觉：字号底线、状态标签收成一套、橙色收窄（质感不动，只动字号和标签）。

## 六、还没定的

- 汇报页的六个数字（派了单、提交 PR、完成合并、秘书替你定、等你处理、工人用时）和一夜时间轴：并进「今天」右栏、挪去记录页，还是删，盘问没问到。
- 「经过」的白话由猛鬼兽写（新 AI 功能，要登记 AI 接入）：第一版不做，另定。
