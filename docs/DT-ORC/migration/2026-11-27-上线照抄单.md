# 上线照抄单（2026-11-27 早上，常浩亲手做，约 30–40 分钟）

常浩 11-26 定：48 小时内上线，不再送审、不再逐步核对，问题在用的过程中修。所以这张单只留命令；哪一步报错（出现 `[停下]`、`Error`、`不过`），把那一段输出贴回 Claude 会话，别的不用看。

做完以后：你在飞书私聊猛鬼兽说「让 Claude 给 dt-sandbox 做 xx」→「卫士」发确认卡 → 你点「批准派单」→ 工人做完 → 一分钟内系统自己推分支、开 PR → 合并官按策略合，或者发卡片给你点。

开始前，每开一个终端窗口先跑：

```bash
GATE="/Library/Application Support/DigitalTwin/gate/bin/dt-gate-hub"; cd ~/Documents/ChatGPT/个人/work/digital-twin && git checkout main && git pull
```

## 1. 建发布令牌（GitHub 网页）

浏览器登录 **shanhao1997**（不是你自己的账号）→ 头像 → Settings → Developer settings → Personal access tokens → **Tokens (classic)** → Generate new token (classic)：Note 写 `dt-gate 受信发布`，Expiration 选 90 days，权限**只勾 public_repo**。复制 `ghp_` 开头的令牌，页面先别关，第 5 步要粘贴。

## 2. 工人的 Claude 长期令牌（登录 dt-worker 做）

快速用户切换登录 dt-worker，打开终端：

```bash
bash /Users/Shared/dt-autoloop/setup-dt-worker.sh
```

到 `claude setup-token` 那一步，按提示在浏览器里登录 Claude 会员账号。跑完后注销 dt-worker，回到你自己的账号。

## 3. 换工人启动脚本、装工人接单服务（你的账号）

```bash
install -m 755 ops/dt_worktree.py /Users/Shared/dt-autoloop/bin/dt-worktree-claude && install -m 755 ops/dt_worktree.py /Users/Shared/dt-autoloop/bin/dt-worktree-codex
```

```bash
sudo /usr/bin/python3 -B -E -s ops/dt_worker_service.py install
```

退出码 3（说「在等门卫」）也算装好了，接着往下做。

## 4. dt-gate 换到新代码（多装一个自动发布服务）

```bash
sudo /usr/bin/python3 -B -E -s ops/dt_gate_hub.py stage --engine-repo ~/Documents/ChatGPT/个人/work/agent-autoloop --engine-commit abc8d41efdc97efe4c25bac8376460424baec726 --repo ~/Documents/ChatGPT/个人/work/digital-twin --repo-commit "$(git rev-parse HEAD)" --node ~/.nvm/versions/node/v24.16.0/bin/node --gh /opt/homebrew/bin/gh
```

```bash
sudo "$GATE" update --confirm
```

## 5. 放令牌

```bash
sudo "$GATE" put-publish-token --confirm
```

提示粘贴时，粘贴第 1 步的令牌、回车（屏幕上不显示）。最后一行是「令牌核对通过」就行，然后关掉 GitHub 的令牌页面。

## 6. 打开真发布、恢复 Codex 派单

```bash
sudo "$GATE" publish on --confirm
```

```bash
sudo "$GATE" run agent-autoloop resume dispatch-dt-sandbox-codex
```

## 7. 回 Claude 会话说「装完了」

Claude 接着核对服务在不在跑、开关开没开，然后你在飞书真派第一单。

## 要停的时候（平时不用）

关真发布：`sudo "$GATE" publish off`。停一单：飞书里跟猛鬼兽说「停掉 <单号>」。
