先取引擎最新的 main，记下要装的提交（最后一行应当是「一次性合入上游 v1.10.4（#18）」，不是就停下贴回会话）：

```bash

```

```bash
sudo /usr/bin/python3 -B -E -s ops/dt_gate_hub.py stage --engine-repo ~/Documents/ChatGPT/个人/work/agent-autoloop --engine-commit "$ENGINE" --repo ~/Documents/ChatGPT/个人/work/digital-twin --repo-commit "$(git rev-parse HEAD)" --node ~/.nvm/versions/node/v24.16.0/bin/node --gh /opt/homebrew/bin/gh
```

```bash

```

中台换了版本，恢复闸会自己关上（发飞书、发布都暂停），锁定新版本再对一次账才开：

```bash

```

`status` 里中台健康检查的提交号应当等于 `$ENGINE`。
