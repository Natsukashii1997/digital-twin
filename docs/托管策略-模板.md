## 1. 默认托管时段

- 每晚 23:30 到次日 08:00（Asia/Shanghai），周末照常。
- 常浩当晚在私聊说「今晚不托管」，当晚不托管；白天说「托管到 X 点」可以临时开。
- 常浩在任意时刻说「我回来了」「停止托管」，或在驿窗关开关，立即结束。

## 2. 托管期间允许的动作

| 动作 | 允许 | 上限 |
|---|---|---|
| 回复 Claude / Codex 会话的提问、待决事项（以常浩身份，附代发标记） | 是 | 每条链 20 次，每次托管 60 次 |
| 答批准卡（允许 / 拒绝） | 是；Codex〔待执行点闸实测〕前只回复、不答批准 | 计入上一行 |
| 合并 PR | 是，只按 ARCHITECTURE 5.5「托管合并」全部条件，只经 `merge_act.py` | 每次托管 〔填，例：5〕 个 |
| D23 夜间提案没回复时按推荐组合派单 | 是 | 沿用 D23：一晚最多 3 单、每单 ≤2 小时、同一时间 1 单 |
| 待决提案（周一）按推荐 | 〔填：是 / 否〕 | — |

## 3. 一律挂起（不论是否在上表）

- 常设授权清单 D 档的全部动作；
- 一切撤不回的动作；
- L3 改动；
- 改已经由常浩定过的内容（规则、设计、已定行为）；
- 猛鬼兽回退到备用模型期间，需要模型判断的决定；
- 拿不准的。

## 4. 汇报

托管结束后发飞书汇报，逐条带「推翻」。次日 08:00 个人项目日报引用这份汇报。

## 5. 签署

常浩在猛鬼兽私聊发「签托管策略 v〔版本号〕」，猛鬼兽把本文件原样存到上面的位置并回读确认；或常浩亲手把文件放到该位置。转述、模型自报都不算签署。
