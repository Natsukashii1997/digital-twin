# 工作台和飞书分工：飞书叫你、管批准，工作台只看、不催

2026-11-24 常浩在工作台定位盘问第 1 轮定（「都按推荐」）。飞书已经在推日报、午晚单、门卫卡、合并卡、托管单，工作台又在首页、汇报、主线三处各画一份「等我拍板」，而按 PRD F11.7 工作台上点了只算发起、还得去飞书再点一次，结果同一件事最多出现在六个地方。决定：**飞书负责叫常浩，也是他按下批准的唯一地方；工作台不催，只回答飞书一句话说不清的东西（全貌、来龙去脉、规则），第一版只看不改**，能点的只有跳转和「关秘书」刹车。工作台的「等你定」只出数字和「去飞书 ↗」。

## 考虑过的

- 工作台也作拍板入口、和飞书并列：批准仍只能落在门卫卡（ADR-015 不改），两边都做等于让常浩跑两边。
- 以工作台为主、飞书只留紧急提醒：要在工作台另做身份核验，和 ADR-015 的信任边界冲突。
- 照设计稿保留拖泳道、切执行方、发起合并等「改」的入口：存改动的地方和对应的门卫卡都还没有；先把「看」做到每天真有用，「改」以后单独定。

## 后果

- 首页拍板清单行、汇报页拍板卡片、主线页「等你」横条要拿掉，协同页拖拽编辑整段去掉（都是已定内容，动设计稿前逐项改动确认）。
- PRD F11.4（工作台里改工作流先进等我拍板）、F11.7（按钮只算发起）在第一版里用不上，留着等「改」重新定。
- 页面每块落在哪、留什么见 [工作台页面定位](../工作台页面定位.md)。
