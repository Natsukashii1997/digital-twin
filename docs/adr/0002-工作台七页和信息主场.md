# 工作台从八页改成七页，每类信息只有一个主场

2026-11-24 常浩在工作台定位盘问第 2–6 轮定，impeccable 评审（21/40）佐证：八页一页一页单独定稿，从没整体排过，同一信息被画三到五遍，数字互相打架（拍板 6 / 3 / 4，今天跑了 9 / 66，自动化 8+1 / 21）。决定：

1. **首页和汇报合成「今天」**：每天看一次的就是这一页，回答「从上次看到现在变了什么」；刊头元素全留、换装五个问题的答案，主栏是「经过」。
2. **主线改成「在办」**：收所有分身经手、还没完的事（不按项目划，包括常浩自己开、分身在盯的会话），按状态排，主线压成进度行。
3. **协同、执行、分身三页留着，归侧栏最下面的「规则」组**，只放不变的规则；会变的状态只在出问题时进「今天」。常浩没接受把三页合成一页：合了只是把三屏塞进一个长页，乱的根子是状态和规则混在一起，不是页数。
4. **每类信息只有一个主场**（主场表见 [工作台页面定位](../工作台页面定位.md) 第三节），别处只放同一个数加 ↗，所有数从同一口径算；「今天」从 04:00 算，「经过」从上次打开工作台算。
5. **质感不动**：刊头、等距插画、点阵字等保留，只换内容（常浩第 4 轮纠正：「页面质感不能动」）。

## 后果

- 侧栏从四组八入口改成三组七页；首页、汇报、主线、记录、沉淀、执行、分身、协同八处已定内容都要逐项改动确认后才改设计稿。
- 数据约定（[工作台数据约定](../工作台数据约定.md)）要按七页重新归行；没有数据来源的块画灰框，不放示例数据。
- 以后再加页，先回答它是哪类信息的主场、什么时候看、看完做什么；答不出来就不加。
